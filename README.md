# AdotaPet

Sistema demonstrativo desenvolvido em React para o seminário de Frameworks Web.

## Funcionalidades

- Login
- Cadastro de usuário
- Catálogo de animais
- Pesquisa e filtros
- Detalhes do animal
- Solicitação de adoção
- Minhas solicitações

## Tecnologias

- React
- Vite
- React Router
- JavaScript
- CSS
- LocalStorage

## Executar projeto

```bash
npm install
npm run dev

Aí você clona o projeto e desenvolve:
